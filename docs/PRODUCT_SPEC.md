# GFES (GreenFin Eco System) Product Specification

## 一句話定位

GFES 將綠色消費循環與小農綠色數位履歷整合為單一平台：消費者以綠點支持在地，小農治理並累積可追溯資料，金融機構在有效授權下取得可解釋的授信補充資訊。

## 使用者

- 消費者：完成綠色行動、取得綠點、支持小農改善專案或兌換農產。
- 小農：管理商品、專案、證據文件、GreenFin 履歷、資料品質及銀行授權。
- 銀行／政府／企業：管理激勵計畫及 ESG 成果；金融機構另可查看已授權的 GreenFin 案件。
- 管理員：管理帳號、平台資料與 Demo 環境，但不得代替銀行作授信決策。

## GreenFin 三項獨立輸出

1. 經驗值：四構面綠色行動的累積進度，不是信用分數。
2. 四大分析指標：資料完整度、資料可信度、經營成熟度、綠色成熟度。
3. Data Health：各資料領域的即時品質狀態、原因及改善行動。

## 必要流程

```text
原始文件 → 上傳 → OCR／欄位擷取 → 人工確認 → 標準化
→ 來源核驗 → 異常檢查 → Data Health／經驗值／四大指標
→ 小農授權 → 銀行案件 → 證據追溯 → 授信補充資料包
```

## 產品邊界

不得產生或暗示信用總分、核貸／拒貸機率、違約機率、建議額度、建議利率或自動授信決策。
