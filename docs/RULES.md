# GreenFin Rules

所有參數均為 Demo／PoC 初始值，正式上線前須經場域、專家與金融機構校準。

## Rule Set

目前版本：`GREENFIN_DEMO_V1`。

任何計算結果都必須保存規則版本、計算時間、輸入證據及計算追溯。規則更新不得覆蓋歷史結果。

## 來源強度

- V3：官方或合作系統直接核驗。
- V2：可查核第三方文件。
- V1：自行提交且部分佐證。
- V0：無法使用或確認異常。

## 經驗值

- 四構面：減量、增匯、循環、綠色治理。
- 每構面年度上限 250，總上限 1000。
- 單次基礎行為 20、持續性措施 50、正式驗證／重大投入 100。
- 單筆有效值 = 基礎值 × 規則設定中的來源認列比例。

等級：L0 = 0；L1 = 1–200；L2 = 201–400；L3 = 401–600；L4 = 601–800；L5 = 801–1000。

## Data Health

判定優先序：未授權／不適用為 GRAY；重大異常／核心缺件為 RED；一般缺漏／待確認為 YELLOW；其餘符合為 GREEN。

每筆結果必須包含 `status`、`reasons[]`、`actions[]`、`affected_evidence_ids` 及 `rule_version`。

## 禁止推論

所有規則均不得產生核貸機率、違約機率、額度、利率或信用總分。
